# LayF AI BOT

Юзербот Telegram с ИИ-автоответчиком + сайт управления, размещается на **Vercel**.

- Автоответчик отвечает **от имени владельца аккаунта** (по жёсткому промпту, как человек).
- **Память переписок** — учитывает историю диалога.
- QR-авторизация аккаунта с сайта (Telethon QR), 2FA подставляется автоматически.
- Админ-панель (логин/пароль).
- Контролирующий Telegram-бот: `/session`, `/on`, `/off`, `/status`, `/logout`, `/clear`.
- Сессия хранится в Vercel KV (Upstash Redis) или локальных файлах.

> ⚠️ **ВАЖНО.** Юзерботы нарушают [Telegram ToS](https://telegram.org/terms) — аккаунт могут ограничить или заблокировать. Используйте на свой страх и риск, лучше на запасном аккаунте. Vercel Hobby (бесплатный план) ограничивает длительность функций (~10–60 c), поэтому ответы могут приходить с задержкой до 1–2 минут; для быстрых ответов 24/7 нужен Pro/VPS.

## 1. Что нужно

| Что | Где взять |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | https://my.telegram.org → API development tools |
| `OPENROUTER_API_KEY` | https://openrouter.ai/keys (уже в `.env`) |
| `CONTROL_BOT_TOKEN` | @BotFather (уже в `.env`) |
| Vercel KV | https://vercel.com/dashboard → Storage → Create → KV (выдаст `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`) |

## 2. Локальный запуск (для проверки)

```bash
cd layf-ai-bot
pip install -r requirements.txt
# заполни .env (TG_API_ID / TG_API_HASH и т.д.)
uvicorn api.index:app --reload
```

Открой `http://localhost:8000`, войди в админ-панель (`LayF` / `sashalordan`),
нажми «Подключить по QR», отсканируй в Telegram:
**Настройки → Устройства → Привязать устройство**.

## 3. Деплой на Vercel

1. Залей проект в Git-репозиторий (или import напрямую).
2. На Vercel: **New Project → Import**.
3. В настройках проекта задай переменные окружения (Framework Preset не нужен, Python определится сам):
   - `TG_API_ID`, `TG_API_HASH`
   - `OPENROUTER_API_KEY`
   - `CONTROL_BOT_TOKEN`
   - `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`
   - `ADMIN_USER`, `ADMIN_PASS` (обязательно поменяй дефолтные!)
   - `CONTROL_ADMIN_IDS` — твой числовой Telegram id (для команд управляющего бота до первого логина)
4. `vercel.json` уже настроен:
   - cron каждую минуту → `/api/worker`
   - регион функций `cle1` (США; в Colorado региона у Vercel нет — это ближайший штат)
5. Управляющий бот: напиши боту `/start`, затем команды работают.

### Смена модели

В `.env` / настройках Vercel поменять `AI_MODEL`. Варианты бесплатных моделей OpenRouter:

- `meta-llama/llama-3.3-70b-instruct:free` (умная, многоязычная; может цензурить мат)
- `gryphe/mythomax-l2-13b:free` (нецензурщина/агрессия лучше, но менее «умная»)
- `qwen/qwen-2.5-72b-instruct:free`
- `deepseek/deepseek-chat-v3-0324:free`

## 5. Команды контролирующего бота

| Команда | Действие |
|---|---|
| `/session` | скинуть код сессии (тот самый «кеш») |
| `/on` / `/off` | включить / выключить автоответчик |
| `/status` | статус |
| `/logout` | отключить аккаунт, удалить сессию |
| `/clear` | очистить память переписок |

### Восстановление сессии («вставить в консоль»)

С кодом сессии от управляющего бота открой сайт управления (будучи залогиненным)
и в консоли браузера (F12) выполни:

```js
await LayF_Connect('КОД_СЕССИИ')
```

Или вставь код в поле «Сессия вручную» и нажми «Подключить». Аккаунт подключится
и автоответчик включится.

## 6. Как это устроено (архитектура)

- `api/index.py` — FastAPI-приложение: админка, QR-авторизация, API, `/api/worker` (запасной путь cron).
- `api/worker.py` — отдельная серверлесс-функция, которую дёргает cron каждую минуту.
- `bot/auth.py` — QR-логин (Telethon) с автоподстановкой 2FA.
- `bot/worker.py` — фоновый проход: обрабатывает команды управляющего бота + новые сообщения.
- `bot/responder.py` — жёсткий промпт и вызов OpenRouter.
- `bot/memory.py` — память переписок.
- `core/kv.py` — состояние: Vercel KV (Upstash REST) с фолбэком на локальные файлы.

На Vercel невозможно держать постоянное соединение, поэтому «24/7» реализовано
через cron-опрос (раз в минуту). После отклика функции клиент отключается;
сессия (auth-ключ) сохраняется в KV, и при следующем проходе соединение возобновляется.

## 7. Безопасность

- Поменяй `ADMIN_PASS` сразу после деплоя.
- Содержимое `.env` не коммить (уже в `.gitignore`).
- Сессия = полный доступ к аккаунту. Никому не передавай коды сессий.
- Сайт на Hobby-плане без HTTPS-ограничений не закрыт от перебора логина — ставь крепкий пароль.

## 8. Известные ограничения

- Vercel Hobby: максимум 10 c на функцию (повысить нельзя; на Pro — до 300–800 c). Поэтому на Hobby ответы могут не успеть — несделанные сообщения догниваются следующим проходом. На Pro подними `maxDuration` в `vercel.json` (например, до `60`/`300`).
- Бесплатные модели OpenRouter имеют суточные лимиты и могут медленно отвечать.
- Частая переподлключение (каждую минуту) может привлекать внимание Telegram → риск FloodWait/бана.
- Регион `cle1` (Огайо) — ближайший доступный; точного «Colorado» у Vercel нет.
